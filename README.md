# UMP EO Training

Earth Observation (EO) practical notebooks for rainfall, surface water, vegetation response, and optional pond mapping in the Lower Moulouya basin (Morocco), using Google Earth Engine and geemap.

This material is organised within the **SEMIA'04 event**, organised at **UMP, Morocco**, **12-16 May 2026**.

## Brief Plan

1. Set up Google Earth Engine access and environment.
2. Define the area of interest (Lower Moulouya basin) and terrain context.
3. Compare wet-season rainfall patterns and anomalies.
4. Assess surface water change between seasons.
5. Evaluate vegetation response (NDVI change).
6. Optionally run a Random Forest workflow to identify irrigation ponds.
